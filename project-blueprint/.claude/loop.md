# `/loop` の既定プロンプト(引数なしの `/loop` で使われる。`.claude/loop.md` が無ければ組み込みの保守プロンプト)

このセッションの続きを、次の優先順で 1 反復ぶんだけ進める。新しい取り組みは始めない。

1. 会話に未完了の作業があれば、それを続ける
2. `output/tasks/PROGRESS.md` があれば「次にやること」の先頭 1 件だけを進め、
   検証コマンドを実行し、その結果を根拠に `passes` とセッションログを更新する
3. 現在のブランチに PR があれば、失敗した CI・レビューコメント・コンフリクトに対応する
4. 何も無ければ `/code-review` で差分を点検し、MUST だけ直す

守ること:

- 各反復の終わりに、変更ファイル・実行した検証と結果・次の一手を 3 行以内で報告する
- push・merge・削除など不可逆な操作は、会話で既に承認された作業の続きでない限り行わない
- 検証していない作業を「完了」と報告しない。手詰まりなら理由を書いて次の反復に回す
- CI が緑で PR も静かなら「変更なし」と 1 行で返す
